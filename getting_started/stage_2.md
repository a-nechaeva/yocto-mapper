# Другие пути нахождения CVE

## VulnScout 
В виде слоя `meta-vulnscout`. Это open-source инструмент, который создан специально для анализа SBOM из Yocto. Он умеет собирать данные из нескольких источников (NVD, OSV, а также напрямую парсить вывод штатного `cve-check`) и предоставлять результаты в удобном для анализа виде. Это может быть хорошей альтернативой ручному `jq` по JSON-файлам.

## `cve-check` с расширенным парсером.

Есть скрипты (например, `improve_kernel_cve_report.py` из `poky/scripts/contrib/`), которые позволяют отфильтровать ложные срабатывания для ядра Linux, отсекая те CVE, код для которых не был скомпилирован.
